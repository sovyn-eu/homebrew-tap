# sovyn-eu Homebrew tap

```sh
brew tap sovyn-eu/tap
brew trust --formula sovyn-eu/tap/skiff
brew install sovyn-eu/tap/skiff
skiff prepare
```

Homebrew 7 loads formulas from taps outside Homebrew only once you trust
them; `brew trust --formula` covers just that formula.

| Formula | What it is |
|---|---|
| `skiff` | [skiff](https://github.com/sovyn-eu/skiff): throwaway Linux VMs on Apple Silicon, one per task or coding agent |

The formulas here are generated by the release workflows of their projects
and overwritten on every release, so please send changes to the project
itself rather than to this repository.
